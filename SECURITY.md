# Security Policy

## Supported Versions

Security updates are provided for the latest published version of Registry Hive Viewer.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through the **Security** tab of this extension's GitHub repository by selecting **Report a vulnerability**. If private vulnerability reporting is unavailable, use the contact method on the extension publisher's Visual Studio Marketplace profile to request a private reporting channel. Do not include vulnerability details in a public GitHub issue.

Include the affected version, reproduction steps, expected and actual behavior, and any known impact. Registry hives and generated search caches can contain sensitive data; remove personal or confidential information from samples, logs, and screenshots before submitting them.

This is a personal, independently maintained project. Security reports are reviewed on a best-effort basis.

No response, investigation, fix, release, or disclosure timeline is guaranteed. Submitting a report does not guarantee that it will be accepted as a vulnerability or that a fix or mitigation will be provided.

A report may be declined if it is outside the project's scope, cannot be reproduced, or does not present a practical security risk in the supported usage model.

For ordinary bugs and feature requests, use the [public issue tracker](https://github.com/kemats/vscode-reg/issues).
